Original FPGA family, and the CAD that builds for it.

Helion is not a vendor skin. Synth, pack, PathFinder route, STA, bitstream, and a desktop IDE all hit the same Session. One owner. A real device family (HAD). Apache-2.0 OR MIT. If you write Rust, SystemVerilog, STA, or docs — we need you.

IO ring CLK spine x=1 32×32 CLB

Prove it in one minute

git clone https://github.com/helion-fpga/helion.git
cd helion
cargo test --workspace
cargo run -p helion-gui --bin helion-ide -- --headless examples/counter.sv
# empty-XDC counter gold: WNS_PS=9640
# fabric LED: helion run examples/counter.sv --cycles 16

macOS app: ./scripts/build-macos-app.sh then open dist/Helion.app. The GUI binary is Helion / helion-ide, not the CLI.

Flow

helion-sv→ pack→ place→ PathFinder→ STA→ drc→ .hbits

Device facts come from the Helion Architecture Database. Nothing in the CAD hardcodes a vendor die.

We need help with

SV ingest

STA / XDC
Clocks, I/O delay, false paths — gold counter stays WNS_PS=9640.
IDE
Engine-backed panes and tests, not caption dumps. Floorplan, wave, timing, netlist.
Docs / CI
This site, Linux + macOS CI, good first issues. If you cannot write CAD yet, you can still land here.
