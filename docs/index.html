v3.0 · Xilinx 7-series backend

One binary. The whole FPGA flow. Two device families.

Helion is an FPGA CAD suite, not a vendor-tool wrapper. Write SystemVerilog or VHDL, run one command, and get a placed, routed, timing-closed bitstream for the HL10T die or Xilinx 7-series parts. Deterministic, fail-loud, and measured. Empty-XDC counter.sv gold is WNS_PS=9640.

What it does

Compile

SystemVerilog / VHDL-2008 frontend, AIG synthesis with ABC-style rewriting, LUT6/FF/DSP/BRAM packing, simulated-annealing placement, PathFinder routing, graph STA with WNS/TNS and hold checks.

Xilinx 7-series

xc7a35t device model from open bitstream databases. Pack, place, route, FASM emission, frames-to-bitstream, all in Rust, zero vendor tools. FASM output byte-identical to prjxray's encoder.

Verify

SAT-based combinational equivalence checking, SystemVerilog assertions (immediate and concurrent), and clock-domain-crossing structural analysis with 11 violation classes, all in the IDE.

Inspect

Physical View 2.0 with congestion and timing heat maps, design runs with strategy sweep, checkpoints, testbench runner, constraints wizard, VCD-driven power, integrated logic analyzer.

Why Helion

  • One binary, whole flow. helion implement design.prj runs synthesis → packing → placement → PathFinder routing → STA → bitstream. No toolchain stitching.
  • Deterministic. Same RTL in, same bits out. The QoR gate fails the build if LUT counts, WNS, or bitstream bytes move without a reason recorded in the same commit.
  • Fail-loud. Over-capacity designs error instead of emitting a clipped bitstream; congested routing is refused, never silently clipped.
  • Measured, not claimed. Every number on this page traces to the benchmark report or a pushed commit.
  • Multi-vendor by design. NetlistIR plus a Backend trait. HL10T and Xilinx 7-series are the first two backends, not the only ones.

Get it

GitHub Releases publish Helion.app (Apple Silicon), a darwin-arm64 tarball with CLI + IDE + HAD + examples, a Linux x86_64 tarball (CLI + headless IDE), and SHA256SUMS.txt. The app is ad-hoc signed; on first launch clear the quarantine flag once with xattr -cr /Applications/Helion.app. 

git clone https://github.com/helion-fpga/helion.git
cd helion
cargo test --workspace
cargo run -p helion-cli -- doctor
cargo run -p helion-cli -- run examples/counter.sv --cycles 16
cargo run -p helion-gui --bin helion-ide -- --headless examples/counter.sv
