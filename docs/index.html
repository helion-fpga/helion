What it does

Each step is a crate. The Tcl session drives the same engines the CLI uses.

CompileSynth to bitstream

SystemVerilog / VHDL frontend, AIG-based synthesis with ABC-style rewriting, LUT6/FF/DSP/BRAM packing, simulated-annealing placement, PathFinder routing, graph-based STA with WNS/TNS and hold checks.

Xilinx 7-seriesSecond backend

xc7a35t device model from open bitstream databases. Pack, place, route, FASM emission, frames to .bit, all in Rust, zero vendor tools. FASM output byte-identical to prjxray's encoder.

VerifyProve it, don't eyeball it

SAT-based combinational equivalence checking, SystemVerilog assertions (immediate and concurrent), and clock-domain-crossing structural analysis with 11 violation classes, integrated in the IDE.

InspectSee everything

Physical View 2.0 with heat maps and inspector, schematic level-of-detail for large designs, waveform viewer, cross-probing, real Tcl console, integrated logic analyzer, VCD-driven power.

Why Helion

  • ✓
    One binary, whole flow.

    helion implement design.prj runs synthesis through bitstream. No toolchain stitching.

  • ✓
    Deterministic.

    Same RTL in, same bits out. The QoR gate fails the build if LUT counts, WNS, or bitstream bytes move without a reason recorded in the same commit.

  • ✓
    Fail-loud.

    Over-capacity designs error instead of emitting a clipped bitstream. Congested routing is refused, never silently clipped.

  • ✓
    Measured, not claimed.

    Every number on this page traces to the benchmark report or a pushed commit.

  • ✓
    Multi-vendor by design.

    NetlistIR plus a Backend trait. HL10T and Xilinx 7-series are the first two backends, not the only ones.

Get it

Prebuilt binaries on the releases page: Linux x86_64, macOS arm64, plus SHA256SUMS.txt. Or build from source with Rust 1.85+.

git clone https://github.com/helion-fpga/helion.git
cd helion
cargo test --workspace
cargo run -p helion-cli -- run examples/counter.sv --cycles 16

macOS note: the app is ad-hoc signed, not notarized. Clear the quarantine flag once: xattr -cr /Applications/Helion.app
