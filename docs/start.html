Getting started

There is no installer. Clone the tree, run the gold, then open the IDE. Native desktop target is Apple Silicon; CI is Linux.

Needs

  • Rust 1.85+ (rustup toolchain install 1.85.0)
  • Git
  • On macOS: Xcode Command Line Tools if you want Helion.app

Build and gold

git clone https://github.com/helion-fpga/helion.git
cd helion
cargo test --workspace
cargo run -p helion-cli -- doctor
cargo run -p helion-cli -- run examples/counter.sv --cycles 16
cargo run -p helion-gui --bin helion-ide -- --headless examples/counter.sv

Empty-XDC counter gold is WNS_PS=9640 and LED waveform LED[16]=0000000111111110 (LED = cnt[3]).

Desktop IDE (macOS)

./scripts/build-macos-app.sh
open dist/Helion.app

The windowed binary is Contents/MacOS/Helion (same as helion-ide). Do not launch the CLI as the app. HAD and examples ship under Contents/Resources/.

Without the bundle:

cargo run -p helion-gui --release --bin helion-ide

While you iterate

Run one test name, not the world:

cargo test -p helion-sv --lib TESTNAME

Large SystemVerilog

examples/ysyx_ibex.sv is in the tree (Open rail in the IDE). Ingest is helion-sv preprocess + parse. Fitting a full SoC on HL10T-C32-1 is not the synth bar. Do not abort the run because sv-parser is unhappy — leftover Helion-legal constructs still map.
