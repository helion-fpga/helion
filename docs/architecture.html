Architecture

One Session, many crates. Device facts live in HAD TOML. The IDE paints that Session; it does not reimplement CAD.

Pipeline

helion-sv / vhdl / hls  →  HNF
helion-pack → place → route (PathFinder)
helion-sta (XDC) → helion-drc → helion-bits
helion-fabric / helion-sim / helion-hw
helion-gui IdeModel paints the Session

Part HL10T-C32-1

32×32 interior CLB, IO on the ring, clock spine at x=1, 32 user IO, 8 BRAM18, speed 1. Grid is in devices/helion/parts/HL10T-C32-1.toml — CAD must query that file. How to open it in the IDE: Use.

Gold

Empty-XDC examples/counter.sv → WNS_PS=9640. QoR table in the repository README is gated; a LUT/WNS/bitstream-size change must update the table in the same commit with a reason.
