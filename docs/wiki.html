What Helion is

Helion is an original FPGA family, HL10, and the open-source CAD suite that targets it: synthesis, packing, placement, PathFinder routing, static timing, DRC, bitstreams, simulation and hardware debug. The same engines also target Lattice iCE40, Lattice ECP5 and Xilinx 7-series parts through backends built on open bitstream documentation. The desktop IDE is helion-ide and the command-line tool is helion. It is not a wrapper around a vendor tool.
