Wiki

Helion is an original FPGA family plus the CAD and desktop IDE that target it. This site is the documentation. The pages below carry commands, part facts, and gold numbers. They are not a slogan index.

What Helion is

Original device family HL10T-C32-1 (HAD: 32×32 CLB, 32 user IO, idcode 0x00011A1F) and in-repo CAD: synth, pack, place, PathFinder route, STA, DRC, sparse .hbits, fabric sim. Desktop IDE is helion-ide. CLI is helion. Not a wrapper around a vendor tool. Gold: empty-XDC counter.sv WNS_PS=9640, LED 0000000111111110. License Apache-2.0 OR MIT. Full statement: home.

Run the app

Start is download and build: v1.0.1 zip and tarballs, rustc 1.85, Helion.app layout, HELION_HAD, and the gold commands. Use is the user guide: activity rail (Files / Device / Timing / Simulate / Program / Reports), More overflow, full helion command list, Tcl Session, IP, ILA, program honesty.

How it is built

Architecture is the crate map, HAD table, HNF IR, FeatureMap bitstream, and Tcl engines. Legal fence is the no-vendor rule: no Project X-Ray, no UNISIM, no vendor Tcl, no AMD / Intel / Lattice backends, HAD-only device facts, Helion-MM / Helion-ST buses.

Contribute

Get involved is the on-ramp (Discussions, good first issues, sponsor). Start coding is crate paths and PR rules. Gold must stay WNS_PS=9640 unless the QoR table moves in the same commit with a reason. Repo files: CONTRIBUTING.md, GOVERNANCE.md.
